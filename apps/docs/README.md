## Planned Documentation

- **Getting Started** — installation and first run
- **Keyboard Shortcuts** — full reference of all Neovim-style bindings
- **Installation Guide** — how to install software through the app
- **Contributing** — how to add or update software entries
- **Data Format** — the schema for software entry contributions

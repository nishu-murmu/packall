# 14 Core Software Categories

Almanac organizes all software into 14 distinct categories covering everyday desktop needs, server stacks, development workflows, and system administration.

## Categorization Breakdown

| Category | Slug | Description | Examples |
|---|---|---|---|
| **Browsers** | `browsers` | Web browsers and privacy tools | Firefox, Brave, Chrome, Chromium, LibreWolf, Zen |
| **Communications** | `communications` | Chat, email clients, IRC & VoIP | Discord, Slack, Thunderbird, Matrix/Element, Telegram |
| **Development** | `development` | Editors, IDEs, toolchains, APIs | VS Code, Neovim, Zed, Postman, GitKraken, JetBrains |
| **Documents** | `documents` | Office suites, markdown, PDF readers | LibreOffice, Obsidian, Logseq, OnlyOffice, Zotero |
| **Games** | `games` | Launchers, compatibility layers, emulators | Steam, Lutris, Heroic Games Launcher, RetroArch |
| **Multimedia** | `multimedia` | Audio/video players, streaming, DAW | VLC, Spotify, OBS Studio, Audacity, Kdenlive |
| **Self-Hosted** | `self-hosted` | Local servers, clouds, dashboards | Nextcloud, Docker, Portainer, Plex, Jellyfin |
| **Utilities** | `utilities` | Archivers, password managers, remote access | Bitwarden, 1Password, AnyDesk, Peazip, BleachBit |
| **Terminal** | `terminal` | Shell emulators, multiplexers | Alacritty, Kitty, WezTerm, tmux, Zellij |
| **System** | `system` | Monitoring, benchmarking, kernels | btop, htop, Stacer, Timeshift, GParted |
| **Security** | `security` | VPNs, encryption, firewall GUI | Wireshark, VeraCrypt, KeePassXC, UFW Gufw |
| **Virtualization** | `virtualization` | Hypervisors, containers, sandboxes | VirtualBox, QEMU/KVM, Podman, Distrobox |
| **Education** | `education` | Science, planetariums, math software | Stellarium, GeoGebra, Anki, KiCad |
| **Graphics** | `graphics` | Raster/vector editors, 3D modelling | GIMP, Inkscape, Blender, Krita, Darktable |
